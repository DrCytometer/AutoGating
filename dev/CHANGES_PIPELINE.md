# Model I/O and pipeline (2026-11-11)

Plan: project doc `claude/AUTOGATING_R_REVIEW_PLAN.md`, Part E Phase 3. Assumes the data-layer and gate-engine changes (`CHANGES_DATA_LAYER.md`, `CHANGES_GATE_ENGINE.md`) landed.

New
- `R/agmodel_io.R`: `read.agmodel(path, panel)`, `write.agmodel(model, path, panel)`, `new.agmodel()`; internal JSON conversion (keys renamed only; data names and string values kept), `normalize.agmodel` (Honeychrome's normalize_model defaults, "/"-ending stats parents, cycle check, untrained list), channel renaming dye <-> antigen with a panel. metadata / training_summary / af / qc and each gate's `source` kept as read (JSON key names). Numbers written with 17 significant digits (exact round trip).
- `R/transform.R` (appended): `same.transform`, `densify.polygon`, `remap.boundaries`, `remap.model` (port of ag_core remap_boundaries / remap_model).
- `R/convert_gate_definitions.R`: `convert.gate.definitions(population.gates, activation.gates)`; rules in the file header. ST1 needed one rule beyond the plan: four gates whose parent is two populations of one gate (tem and temra) get a union population `tem.or.temra` (region x-y-|x+y-) added to that parent gate.
- `tests/testthat/test-agmodel.R`; `scripts/agmodel_reference.py`, `scripts/agmodel_check_test.R`.

Rewritten
- `R/define_gates.R`: `define.gates(fcs.setup, ap, model = NULL, retrain = FALSE)` returns a model: from `model`, else `ap$model.filename` (.agmodel), else the R gate files converted; remapped to the data's transforms; gates without a stored boundary trained on `ap$events.per.sample` (default 50,000) events per gate.calculation sample, seed `ap$seed`; training_summary as Honeychrome writes it.
- `R/run_autogating.R`: `run.autogating(fcs.setup, model, ap)`: per-sample `run.gating` with the model's application modes, parallel via `AutoSpectral::create.parallel.lapply` when `ap$worker.n > 1` (mclapply allowed on macOS: the gating is plain R); writes population table, marker medians (display and raw units) and gating status CSVs.
- `scripts/analyze.r`: ST1 example calling setup / define / write.agmodel / run (set `fcs.data.dir`).

Edited

- `R/compute_gate_density.R`: grid-cell lookup (findInterval) instead of fields::interp.surface.
- `R/analyze_aux.r`: trim.quantiles and make.rect.boundary removed (old engine only).
- Links to removed functions in wsp_to_autogating.R, calculate_differential_abundance.R, plot_gate.R, setup_autogating.R docs.
- `DESCRIPTION`: - Biobase, flowCore, flowStats, mclust, modeest, fields, sp; + jsonlite; Description rewritten. `NAMESPACE` regenerated by hand to match the roxygen tags (devtools::document() will rewrite it and remove stale Rd files).
